{% comment %} Scaled iframe embed for fixed-width interactive mocks. The mocks are desktop artboards that only hold their layout above ~1000px, so instead of letting them reflow (columns collide) we render them at their native width and scale the whole frame down to fit the column. Params: src — page to frame w / h — native pixel size of the mock title — iframe title (a11y) caption — optional figcaption text, shown before the full-size link {% endcomment %}
